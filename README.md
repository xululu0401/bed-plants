# 一畦几棵苗（bed-plants）

把一条畦从头往后分成几段，每段种一样菜：按行距、株距、方格或三角交错一棵一棵摆好再数，算出每段几行几棵、直播要几粒几袋种子、移栽买几棵苗，画出俯视种植图；给出只改一项就能多种几棵的改法（行株距接近时改三角交错、边距收一点、把畦尾空长分给某段、直播每穴多下一粒），每条回填重算。

- 单文件页面：`index.html`（由 `template.html` 经 `build.cjs` 产出）+ `core.js`（纯计算）+ `ui.js`（界面）
- 测试：`node --test tests/core.test.cjs`（锚点来自 `../evidence/手算锚点.py`，Python Fraction 逐棵摆放计数）
- 公式：能用的长 = 段长 − 2 × 边距，能用的宽 = 畦宽 − 2 × 边距；行数 = ⌊宽 ÷ 行距⌋ + 1，每行 = ⌊长 ÷ 株距⌋ + 1，交错双数行从半个株距起；种子 = 棵数 × 每穴粒数，按袋向上取整；苗 = ⌈棵数 × (1 + 多备比例)⌉；空穴期望 = 棵数 × (1 − 发芽率)^每穴粒数。
- 默认场景为虚构示例；边距、多备比例、交错只在行株距相差 ≤ 20% 时给，都是可改的设计值。
